# HIS-SRE client

React 19 + Vite 8 + Tailwind 4 multi-step wizard.

## Verified runtime

- **Node.js:** v22 LTS or v24 (same as server)
- Dependency versions in `package.json` resolve on the npm registry as of 2026-08-15.

## Scripts

```bash
npm install
npm run dev      # Vite, proxies/calls API at VITE_API_BASE or http://localhost:3001
npm run build
npm run preview
```
